# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we want a welcoming, respectful, harassment-free community for
everyone, regardless of background or experience level. Be kind, assume good
intent, and give constructive feedback.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and
when representing the project in public spaces.

## Reporting

To report unacceptable behavior, contact the maintainer privately through
GitHub (open the maintainer's profile and use the available contact method, or
raise it via a private security advisory if needed). Reports will be handled
confidentially and in good faith.

Enforcement follows the Contributor Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
